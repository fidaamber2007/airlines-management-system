# Airlines Management System

## Project Overview
The Airlines Management System is a database-driven application developed using Python and Oracle SQL. It manages airline operations through a graphical user interface connected to an Oracle database. Used to manage airline operations and passenger information in one place.

## Technologies Used
- Python
- Tkinter (GUI)
- Oracle SQL
- cx_Oracle (Database Connectivity)

## Modules
1. Airport Management
2. Flight Management
3. Passenger Management
4. Reservation Management
5. Staff Management
6. Payment Management
7. Staff Assignment Management

## Features
- Insert records
- Update records
- Delete records
- Store and manage airline information
- Connect Python applications with an Oracle database
- Maintain relational database records

## Project Architecture
- Frontend: Python GUI using Tkinter
- Backend: Oracle SQL Database
- Connectivity: Python database driver

## How to Run
1. Install Python.
2. Install the required Python database package.
3. Configure Oracle Database.
4. Configure your database credentials using environment variables.
5. Execute the SQL table creation scripts.
6. Run the Python application.
